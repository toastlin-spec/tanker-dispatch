# 同事試用說明

感謝幫忙試用油罐車派車系統！目前是**測試版**，資料之後會清空，請放心操作。

## 一、登入

1. 打開系統網址：`（部署後填入）`
2. 按「使用 Google 帳號登入」，選你提供給我的那個 Gmail。
3. 如果出現「**Google 尚未驗證這個應用程式**」，按「**繼續**」。這是測試期間的正常畫面。
4. 如果出現「沒有使用權限」或「存取遭拒」，請把你的 Gmail 傳給我，我幫你加入名單。

操作方式請看[操作手冊](manual.md)。

## 二、請幫忙測這些情境

每項做完，記下「有沒有照預期」就好。

| # | 試試看 | 預期結果 |
|---|---|---|
| 1 | 在「訂單管理」新增幾張訂單：不同油站、不同油品（92、95、98、柴油）、不同數量 | 訂單出現在列表，狀態是「待派」 |
| 2 | 到「調度看板」選同一天，把訂單拖到司機列上 | 時間軸出現色塊，顯示收車時間 |
| 3 | 同一站的 92 和 98 各一張（都 15KL 以下），拖給同一位司機 | 併成同一趟，一艙一種，算 1 單 |
| 4 | 汽油和柴油各一張，拖給同一位司機 | 分成兩趟（汽柴油不能同一趟） |
| 5 | 一張超過 30KL 的訂單 | 自動拆成兩趟，算 2 單 |
| 6 | 台中廠的司機排超過 3 趟 | 出現黃色「警告」，發布時要填原因 |
| 7 | 台中交通站（08:00 才開門）排在一大早送 | 時間軸出現灰色「等待」到 08:00 |
| 8 | 把出車時間改得很晚，讓台中交通站卸油超過 17:00 | 出現紅色「違規」，不能發布 |
| 9 | 日班司機送南部的站（例如嘉益站） | 可能出現「缺少路段時間」，點「補上」到設定頁填時間後重算 |
| 10 | 在「車趟」裡拖曳調整送油順序、改灌油點、移出訂單 | 時間軸立刻重算 |
| 11 | 大夜班（司機D）的車趟把灌油點改成彰濱廠 | 收車時間重算 |
| 12 | 前一天排到很晚收車，隔天一早又排同一位司機 | 出現「間隔不足 11 小時」的違規 |
| 13 | 發布一位司機的班表，再到「派車單」列印或存成圖片 | 派車單內容正確 |
| 14 | 到「設定」改灌油或卸油的分鐘數，回看板 | 收車時間跟著改變 |

也歡迎照你平常排班的方式，排一整天真實的班看看。

## 三、目前已知的狀況（不用回報）

- 司機（司機A～D）和車輛（車1～4）是佔位名稱。
- 有些路段還沒有行車時間，會顯示「缺少路段時間」，這是正常的，可以試著補上。
- 已經發布的派車單，是發布當下的內容；之後修改設定不會改變已發布的派車單。

## 四、怎麼回報問題

用 LINE 傳給我，盡量包含這幾點：

1. **在哪個畫面**：例如「調度看板，11/5，司機B」
2. **做了什麼**：例如「把苗栗站 92 30KL 拖到司機B」
3. **看到什麼**：最好附**截圖**
4. **你覺得應該是什麼**：例如「應該到彰濱灌油，不是 R89」

業務規則覺得不對（例如單數怎麼算、休息幾小時）也請告訴我，這類回饋最有幫助。
